# 職務経歴書（chot-ink 貼り付け用）

> 経験期間は「そのスキルを使っていた**所属会社の在籍期間の合計**」からの推定値です。重複期間は二重計上していません。
> 会社名・サービス名は業界／ドメインでぼかしています。`(推定)` は README に使用時期の明記がなく控えめに見積もった項目です。
> 使用技術は `chot-ink/skill.json` の `is_active: true` な `skill_name` から採用しています（未登録の技術は本文でのみ言及）。
> TypeScript・Node.js は Next.js／React と同じ期間、Storybook は使用が言及された会社の期間を合算する運用です。
> 現職（受託）では複数の案件（医療系 SaaS・不動産情報サービス・記事系モバイルアプリなど）を担当しているため、同一会社内の期間は重複計上していません。
